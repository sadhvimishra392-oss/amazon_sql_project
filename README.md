# 🛒 Amazon Sales Data Analysis Using SQL

A SQL-based data analytics project focused on analyzing Amazon sales data to uncover business insights related to revenue, product performance, customer behavior, and regional sales trends.

---

## 📌 Project Overview

This project uses SQL queries to perform exploratory data analysis (EDA) on an Amazon sales dataset. The objective is to transform raw transactional data into meaningful business insights that can support strategic decision-making.

---

## 🎯 Objectives

- Perform data quality checks
- Identify missing values and duplicate records
- Analyze overall sales performance
- Discover top-performing products and categories
- Evaluate regional sales trends
- Analyze customer ratings and payment preferences
- Track monthly revenue growth
- Apply SQL window functions for ranking analysis

---

## 🛠️ Tools & Technologies

- MySQL
- SQL Queries
- Aggregate Functions
- Window Functions
- Data Analysis

---

## 📊 Data Quality Checks

The following checks were performed:

- Null Value Detection
- Duplicate Record Identification
- Record Count Validation

---

## 📈 Business Analysis Performed

### 1. Total Revenue Analysis
Calculated total revenue generated from all sales transactions.

### 2. Revenue by Product Category
Analyzed which product categories contribute the highest revenue.

### 3. Top Products by Revenue
Identified the top-performing products based on revenue generation.

### 4. Regional Sales Analysis
Compared sales performance across customer regions.

### 5. Payment Method Analysis
Examined customer payment preferences and transaction distribution.

### 6. Customer Rating Analysis
Analyzed product ratings to understand customer satisfaction trends.

### 7. Category-Wise Rating Analysis
Compared average ratings across product categories.

### 8. Discount Analysis
Evaluated average discount percentages by category.

### 9. Monthly Sales Trend Analysis
Tracked revenue trends over time to identify seasonal patterns.

### 10. Product Revenue Ranking
Used SQL Window Functions (RANK) to rank products based on revenue performance.
